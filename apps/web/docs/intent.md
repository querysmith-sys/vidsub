# DESIGN REQUIREMENTS:
Design a modern, premium dark-themed UI for VidSub, a video subtitle adder. Use a near-black navy background, dark slate cards, subtle borders, rounded corners, clean typography, and blue accents for primary buttons and active states. Use green for completed steps and muted gray for inactive elements.

Create a consistent top navigation bar with the VidSub logo on the left, a four-step progress indicator in the center (Upload → Transcribe → Translate → Subtitle), and Settings, Help, and Profile icons on the right.

Design four clean, connected screens:

1. **Upload:** A centered drag-and-drop upload card with a large upload icon, clear instructions, a Choose Video button, and supported formats.
2. **Processing:** A two-column layout with the original video preview on the left and a vertical processing timeline on the right, showing transcription, translation, and subtitle rendering progress.
3. **Translation:** A clean single-column layout with language selectors, translation settings, and an editable transcript table showing timestamps, original text, and translated text. Do not include a video preview or unnecessary right sidebar.
4. **Subtitle Editor & Export:** A two-column layout with the video preview, subtitle overlay, playback controls, and editable subtitle timeline/table on the left. On the right, include subtitle appearance controls, font settings, color, size, position, and export options with a prominent Download button.

Maintain consistent spacing, alignment, component styles, and visual hierarchy across all screens. Use subtle hover effects, polished icons, and responsive layouts. Keep the interface minimal, intuitive, and professional, resembling a high-quality modern SaaS video editing dashboard.

Prioritize visual clarity, balanced layouts, and usability. Avoid excessive gradients, unnecessary decorative elements, cluttered sidebars, or oversized cards. Use realistic placeholder content to make the UI feel complete.
